# C004 unused-class

**Severity:** hint · **Fix:** none

## What it reports

A class that's defined but never used.

## Why it matters

Unused classes are usually leftovers from removed features. They're harmless
to the compiled font but make the code harder to read.

## Notes

On a single file, "never used" means never used in that file. A shared
`classes.fea` will report every class. Lint the whole project (`fea project`)
to see real results, or across every `#ifdef` build (`fea configs`): a class
is reported only if it's unused in every build that contains it.
