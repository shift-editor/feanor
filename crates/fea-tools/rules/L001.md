# L001 undefined-lookup

**Severity:** error · **Fix:** none

## What it reports

A lookup referenced (`lookup Name;` or `sub a' lookup Name;`) that's never
defined, or that's defined after the reference. Runs only when linting a whole
project.

## Why it matters

Compilers reject it ("unknown lookup").

## Example

```fea
feature calt {
    lookup Later;   # L001: lookup Later is used before it is defined
} calt;
lookup Later { sub a by b; } Later;
```
