# T001 unknown-feature-tag

**Severity:** warning (error for a tag longer than four characters) · **Fix:** unsafe (rename to a close registered tag)

## What it reports

A feature tag that isn't in the [OpenType feature tag registry](https://learn.microsoft.com/en-us/typography/opentype/spec/featuretags),
in a `feature` block or an `aalt` reference (`feature smpc;`). `cv01`–`cv99`
and `ss01`–`ss20` are registered. Tags starting with an uppercase letter are
reserved for private use and not reported.

## Why it matters

Applications only turn on registered features. A typo like `smpc` for `smcp`
compiles but never runs. A tag longer than four characters doesn't compile,
and compilers report it with confusing messages.

## Example

```fea
feature smpc {   # T001: 'smpc' is not a registered OpenType feature tag; did you mean 'smcp' or 'smpl'?
    sub a by a.sc;
} smpc;
```

## Fix

Renames the opening and closing tags to a registered tag at most two edits
away (swapping two adjacent letters counts as one). When several are equally
close, each is offered. **Unsafe:** the right choice needs a person.
