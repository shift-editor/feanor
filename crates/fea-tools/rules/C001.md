# C001 class-length-mismatch

**Severity:** error · **Fix:** none

## What it reports

A single substitution between two classes, `sub @A by @B;`, where the classes
have different lengths. A one-glyph replacement (`sub @A by x;`) is valid and
not reported.

## Why it matters

Compilers reject it, with messages like "class has different length (90) than
target (89)" that don't say which glyph is missing.

## Example

```fea
@lc = [a b c];
@sc = [a.sc b.sc];
feature smcp {
    sub @lc by @sc;   # C001: @lc has 3 glyphs but @sc has 2; @sc is missing c.sc
} smcp;
```

When the replacement names follow the targets plus a suffix (`c` → `c.sc`), the
message names the missing or extra glyphs. Otherwise it lists the unpaired tail.

## Notes

Classes are expanded through nested classes and glyph ranges (`a - z`,
`x.001 - x.010`, ends included). The rule stays silent when a class contains
something it can't expand statically: a Glyphs predicate (`$[…]`) or a CID.
