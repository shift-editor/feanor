# L003 empty-block

**Severity:** warning · **Fix:** none

## What it reports

A `feature` or `lookup` block with no rules: nothing but comments,
`lookupflag`, `script` or `language` statements, `featureNames` or
`cvParameters`.

## Why it matters

An empty lookup does nothing wherever it's called, and an empty feature adds
nothing to the font. Usually the rules were deleted or never written.

## Example

```fea
lookup DOTLESS { } DOTLESS;   # L003
feature ss03 {                # L003
    featureNames { name "Alternate a"; };
} ss03;
```

## Notes

A block with a comment containing "automatic" is exempt: ufo2ft inserts
generated rules at a `# Automatic Code` comment, and Glyphs marks generated
features that way. A block that only refers to other lookups (`lookup NAME;`), or an `aalt` that
only lists features, isn't empty.
