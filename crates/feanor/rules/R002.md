# R002 duplicate-substitution

**Severity:** error · **Fix:** none

## What it reports

A glyph substituted twice in one lookup (`sub a by b;` then `sub a by c;`), or
the same ligature sequence twice (`sub f i by f_i;` then `sub f i by fi;`).

## Why it matters

The compilers disagree. For a single, multiple or alternate substitution
fea-rs silently uses the last rule and fontTools feaLib rejects the file, so
the font depends on which tool built it. Both reject a repeated ligature.

## Example

```fea
feature ss01 {
    sub g by g.alt;
    sub g by g.ss01;   # R002: g is already substituted
} ss01;
```

## Notes

The same substitution written twice, with the same result, is harmless and
reported as [R006](R006.md) instead. `aalt` is exempt: there, several `sub a by …` rules for one glyph are how its
alternates are listed. A `lookupflag`, `script`, `language` or `lookup`
statement starts a new lookup, where the same glyph can be substituted again.
