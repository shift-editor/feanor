# E002 stray-semicolon

**Severity:** warning inside a block, error at the top level (as fea-rs reports it) · **Fix:** safe (remove the `;`)

## What it reports

A `;` with no statement to end: a doubled `;;`, or a `;` after a block's
closing `} name;`.

## Why it matters

fea-rs warns about a stray `;` inside a block and rejects one at the top level
of a file, while fontTools feaLib accepts both. A file with one builds with
one compiler and fails with the other.

## Example

```fea
feature liga {
    sub f i by f_i;;   # E002 (warning)
} liga;;               # E002 (error)
```

## Fix

Removes the `;`. **Safe:** it ends no statement, so the compiled font doesn't
change.
