# X001 invisible-character

**Severity:** error · **Fix:** safe for invisible spaces and zero-width characters; none for other non-ASCII

## What it reports

A non-breaking space, zero-width space, joiner, soft hyphen, byte-order mark,
or other non-ASCII character outside comments and strings.

## Why it matters

Feature syntax is ASCII. An invisible character usually arrives by copy-paste,
and compiler errors about it point at a line that looks fine.

## Example

```fea
@caps = [A B C];   # with a non-breaking space between A and B: X001
```

## Fix

Replaces an invisible space with an ordinary space, or deletes a zero-width
character. **Safe:** the text then reads the way it looks.
