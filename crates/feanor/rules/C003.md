# C003 undefined-class

**Severity:** error · **Fix:** none

## What it reports

A class that's used but never defined, or used before its definition. Runs only
when linting a whole project (`feanor project`), since a single file
may rely on classes defined in another.

## Why it matters

Compilers reject it ("undefined glyph class").

## Example

```fea
feature liga {
    sub @missing by f_i;   # C003: class @missing is never defined in the project
} liga;
```

## Notes

`markClass` names count as definitions. Classes that a build tool generates
(Glyphs' automatic classes, ufo2ft's mark classes) aren't in the source, so the
rule reports them; suppress them with `per-file-ignores` or `# noqa: C003`.
