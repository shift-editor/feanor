# G001 glyph-not-in-font

**Severity:** error · **Fix:** unsafe (replace with the closest glyph name)

## What it reports

A glyph name that isn't in the font's glyph list. Runs only when a glyph list is
given (`--glyphs`, or `glyphs` in `feanor.toml`).

## Why it matters

Compilers reject the whole file ("glyph not in font"). Feature code goes stale
when glyphs are renamed or deleted; the compiler error names the glyph but
often points at the wrong line.

## Example

```fea
feature smcp {
    sub agrve by agrave.sc;   # G001: glyph 'agrve' is not in the font; did you mean 'agrave'?
} smcp;
```

## Fix

Replaces the name with the closest glyph in the font (at most two edits away,
where swapping two adjacent letters counts as one). The fix is **unsafe**: the
closest name isn't always the intended one.

## Notes

A hyphenated token whose two ends are both glyphs (`a-z`) is read as a range,
not reported.
