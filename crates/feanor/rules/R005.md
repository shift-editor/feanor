# R005 lookup-has-no-effect

**Severity:** warning · **Fix:** none

## What it reports

A contextual rule that calls a lookup on marked glyphs the lookup has no rule
for, so the call does nothing.

## Why it matters

Compilers accept it, and the rule matches but changes nothing. Usually the
lookup was meant for other glyphs, or the wrong lookup is named.

## Example

```fea
lookup ALT_A { sub a by a.alt; } ALT_A;
feature calt {
    sub e' lookup ALT_A t;   # R005: ALT_A has no rule for e
} calt;
```

## Notes

Only the first lookup called at a position is checked, and only when no
earlier call in the rule could have changed the glyphs (a ligature, multiple
or contextual lookup): later calls see the result, not the glyphs written in
the rule. Reported only when none of the marked glyphs are covered; a lookup that
applies to some of them is assumed to be meant for those. Mark-attachment and
cursive lookups, and rules with classes that can't be expanded, aren't checked.
