# E001 syntax

**Severity:** error (or warning, as fea-rs reports it) · **Fix:** none

## What it reports

A parse error or warning from [fea-rs](https://github.com/googlefonts/fontc/tree/main/fea-rs),
the parser this tool is built on. The message is fea-rs's own.

## Why it matters

A file with a syntax error doesn't compile. The formatter leaves a top-level
item with a syntax error exactly as written, so formatting never makes a broken
file worse.

## Notes

When another rule explains the same text better, the syntax error is dropped
in its favour. For example, a non-breaking space inside a glyph class is
reported as [X001](X001.md) (with a fix), not as "invalid character in glyph
name".
