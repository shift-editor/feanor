# P001 project

**Severity:** error · **Fix:** none

## What it reports

A problem putting a project together: an included file that doesn't exist, an
include cycle or more than 50 levels of includes, or an `#ifdef` / `#else` /
`#endif` that doesn't balance.

## Why it matters

The project can't be built as written, and every other rule runs on an
incomplete document.
