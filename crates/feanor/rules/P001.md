# P001 project

**Severity:** error (hint for an include when linting one file) · **Fix:** none

## What it reports

A problem putting a project together: an included file that doesn't exist, an
include cycle or more than 50 levels of includes, or an `#ifdef` / `#else` /
`#endif` that doesn't balance.

When linting a single file, each `include` gets a hint instead: one file's
lint doesn't follow includes, so what they define isn't checked with it.

## Why it matters

The project can't be built as written, and every other rule runs on an
incomplete document. For a single file, lint the whole project
(`feanor project ROOT`) to check it with its includes.
