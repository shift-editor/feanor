# R006 redundant-rule

**Severity:** hint · **Fix:** safe (remove the redundant rule)

## What it reports

A rule that repeats what an earlier rule in the same lookup already does: the
same substitution or ligature twice, the same kerning pair with the same value
twice, or a contextual rule that never runs because an earlier rule matches
everything it matches and does the same thing.

## Why it matters

It changes nothing, so it's harmless, but it makes the file longer and hides
what the lookup really does. Exported feature code is often full of these.

## Example

```fea
feature kern {
    pos T o -60;
    pos T o -60;   # R006
} kern;
feature calt {
    sub a' lookup ALT;
    sub a' c lookup ALT;   # R006: the rule above already does this for every a
} calt;
```

## Fix

Removes the rule. **Safe:** it never changes what the lookup does.

## Notes

When the repeat does something different (another result, another value, or
another action), it's reported as a conflict instead:
[R001](R001.md), [R002](R002.md) or [R003](R003.md).
