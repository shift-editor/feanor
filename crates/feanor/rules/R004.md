# R004 wrong-lookup-type

**Severity:** error · **Fix:** none

## What it reports

A contextual rule that calls a lookup of the wrong kind: a positioning lookup
from a `sub` rule, or a substitution lookup from a `pos` rule.

## Why it matters

A substitution rule can only call substitution lookups and a positioning rule
only positioning ones, so compilers reject the file. This shows the problem
while you edit, at the call.

## Example

```fea
lookup KERN_T { pos T 50; } KERN_T;
feature calt {
    sub T' lookup KERN_T o;   # R004: KERN_T positions glyphs
} calt;
```
