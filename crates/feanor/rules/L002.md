# L002 unused-lookup

**Severity:** hint · **Fix:** none

## What it reports

A lookup defined outside any feature that's never referenced.

## Why it matters

A standalone lookup only runs when a feature or a contextual rule refers to it,
so this one never runs. Either the reference is missing or the lookup is dead.

## Example

```fea
lookup Never { sub a by b; } Never;   # L002: standalone lookup Never is never referenced, so it never runs
```

## Notes

A lookup defined inside a `feature` block runs where it's defined and is never
reported.
